# Stone-Paper-Scissors-Game
StonePaperScissors is a fun and interactive web-based game built using HTML, CSS, and JavaScript. The game allows players to compete against the computer by choosing between Rock, Paper, or Scissors. It features a clean user interface, real-time score tracking, and dynamic result messages.

Features
Interactive gameplay with clickable images
Random computer-generated moves
Live score updates for both player and computer
Win, lose, and draw result messages
Responsive and attractive UI design
Hover effects and colorful feedback messages
Technologies Used
HTML for the game structure
CSS for styling and layout
JavaScript for game logic and interactivity
How the Game Works
The player selects Rock, Paper, or Scissors.
The computer randomly selects its move.
The winner is decided based on the classic game rules:
Rock beats Scissors
Scissors beats Paper
Paper beats Rock
Scores are updated instantly, and the result is displayed on the screen.

This project is a great beginner-friendly example for learning DOM manipulation, event handling, conditional logic, and basic game development in JavaScript.
